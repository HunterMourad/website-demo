# SHEride Website

This folder contains the SHEride v2 interactive website built from the original v1 prompt and the newer advanced v2 prompt files.

## Files

- `index.html` - the complete no-build web app in one editable HTML file with embedded CSS and JavaScript.
- `uber-women-website-prompt.pdf` - copied source brief.
- `uber-women-website-prompt.docx` - copied source brief.
- `sheride-v2-advanced-prompt.md` - copied v2 source brief.
- `sheride-v2-advanced-prompt.docx` - copied v2 source brief.

## How to View

Open `index.html` in a browser, or use the local preview URL if the server is running:

`http://127.0.0.1:4173/index.html#home`

No build tools or package installation are required.

## Prompt Requirements Covered

- Hash-routed multi-page app layout.
- Sticky navigation with mobile hamburger menu.
- Home, login, signup, rider dashboard, driver dashboard, book ride, safety, about, driver application, and how-it-works pages.
- Green and red SHEride color system.
- Google Fonts via CDN.
- Toasts, modals, mock auth, signup wizard, booking wizard, fare calculator, trusted contact manager, city selector, driver online mode, and earnings chart.
- Smooth scrolling, scroll reveal, count-up stats, and inline form validation.
- Footer includes "Designed by Women. Built for Women."
